一个月前我想给家里换掉那台跑透明代理的路由器。本以为是「搜一下、挑最便宜的、下单」的十分钟决策，
最后变成扫了四个平台 3343 条挂牌、逐条读详情页、算整机价、查 19 颗 CPU 的官方参数，
中途**十次推翻自己的中间结论**。

买贵了不可怕，可怕的是**用一个错的口径排出一张看起来很专业的表**，然后照着它下单。
这篇写的不是「买哪台」，是**二手硬件比价里那些让你排序整个翻过来的坑**——
它们不分品类，你买显卡、显示器、NAS 一样会踩。

最终结果先放这儿：**四核八线程六网口工控机，整机 ¥900**，
比我第一轮「最划算」的那台贵一倍多，但那台的算力和我要换掉的旧路由器**基本持平**——
也就是说，第一轮我差点花钱买了个原地踏步。

---

## 坑一：挂牌价基本是假的，而且是三种假法同时发生

二手工控机挂的绝大多数是**准系统**——不含内存、不含硬盘、不含电源。
这三样的加价**只写在详情页正文里**，搜索列表上一个字都看不到。

实测的落差：

- 挂牌 ¥695 的机器，整机 **¥945**
- 挂牌 ¥848 的机器，整机 **¥1534**
- 而挂牌 ¥450「已含 8G 内存 + 自带电源」的那台，整机仍然是 **¥450**

**在挂牌价口径下，第三台排第五；在整机价口径下，它是性价比第一。**
我第一轮的短名单，排序是错的。

第二种假法：**标题会和正文矛盾**。有一台标题写「ddr4 8G内存+32G硬盘」，
详情页正文最后一行写「你拿到的是主机一台，**4G 内存，64G 硬盘**」。
第三种：卖家的参数表是抄模板的。我最后买的那台，详情页写「内存最高支持 64G」，
而 Intel 官方规格是 **32GB**——不影响使用，但足够说明这些数字不能当权威。

> **口径**：主机 + N G 内存 + 固态 + 电源，全部取卖家自己写的加价；
> 无明码的标「需私聊」并给市价估算、**且标明是估算**。
> 同时给两列：「卖家一站价」和「拆买价（主机 + 自购最低价配件）」——两者互有胜负。

## 坑二：列表价可能只是最低配的起价（这条最狠）

淘宝这个品类几乎全是「一个链接卖十几种配置」。**搜索列表显示的是最低那档。**

实测：列表 ¥379 的商品，¥379 对应的配置是 **J1900 + 无内存无硬盘无电源**——
而 J1900 因为没有 AES-NI，早在我的红线阶段就被排除了。这个链接第一个能用的配置是 **¥799**。
我抓到能拉出分价的 5 个商品，**全是这个模式，没有例外**。

我原以为这是淘宝独有的。直到有人提醒我点开购买页看看——

我推荐的那台「六网口 2.5G，准系统 ¥529，性价比冠军」，
点「立即购买」才弹出四个型号：

| 型号 | 价格 |
|---|---|
| G6305-021 | **¥529** ← 列表显示的就是这档 |
| G6305-022 | ¥559 |
| G7505-021 | ¥899 |
| G7505-022 | **¥929** |

G6305 和 G7505 共用同一块主板，但**性能差 2.5 倍**（CPU Mark 2,022 vs 5,163）。
我拿 G7505 的性能配 G6305 的价格算出来的「¥154 每倍算力，全表第一」，
真实数字是 **¥253**——冠军当场易主。

**判据其实一直摆在页面上**：商品价格显示成**区间**（`¥529 - 929`）就一定有多档。
只是搜索接口和详情接口都只吐最低值，我只看了后者。

> **规矩**：任何平台的挂牌价，在确认它不是区间起价之前，一律不可引用。

## 坑三：卖家主页默认把已售出混在里面

想绕过关键词的局限，直接翻某家店的全部库存，是个好主意。但我抓的是默认的「综合」tab。

那家店：**在售 53 件，已售出 163 件**。我抓到的 190 多条里，四分之三是卖不了的。

更阴的是：**已售商品的详情页照常渲染价格、描述、参数，从页面上看不出任何区别。**
我甚至专门去核对了一遍，看到「¥770、40 人想要、卖家 8 分钟前在线」，
于是很有底气地告诉自己「在售，没问题」。唯一的线索是**收藏按钮消失了**——
而我恰好把收藏失败归因成了工具的兼容问题（这个归因本身也没全错，
那家店的商家版页面确实没有收藏按钮，两件事撞在一起了）。

不过这一坑有个意外收获：**已售价格是极好的成交锚点**。
同一款六网口 N100 工控机，两家在售的挂 ¥1088 和 ¥1159，
而已售出的两条成交价都是 **¥770**。挂牌贵了 41% 和 50%。
拿这个数去砍价，或者干脆等补货，都比照着挂牌价下单强。

## 坑四：卖家的配件报价是市价的 2–4 倍

同一家店，同一个详情页：

| 规格 | 卖家报价 | 市价（二手平台） |
|---|---|---|
| DDR4 4G | ¥140 | **¥38** |
| DDR4 8G | ¥280 | **¥160** |
| DDR4 16G | ¥540 | **¥300** |

所以配件必须**单独扫一张基准价表**，再和「主机准系统价」相加。
内存尤其值得自己买——**内存没有寿命损耗**（坏就是插上不点亮，不存在半年后暴露），
而系统盘的写入量极小，是拆机件风险最低、价差最大的品类。

但低价挂单里混着坏件。我在 DDR4 4G 按价格排序的前几条里，
¥35 和 ¥40 那两条，正文分别写着「坏的 / 故障内存 / **用于摆件、把玩、内存尸体**」。
固态那边同理，最便宜的两条一条写「插上电脑不识别」，一条写「坏的，不认」。

> **按价格排序之后，必须逐条读标题正文。** 这句话看着像废话，但排序页面本身诱导你不这么做。

还有一个更隐蔽的：**内存代际决定整机价，往往比芯片型号影响更大**。
同期实测 DDR3L 4G ¥25、DDR4 4G ¥38、DDR4 8G ¥160、**DDR5 8G ¥420–628**。
一台「只有一个 DDR5 内存槽」的准系统，会因此整机凭空贵四百多块，
**而这在挂牌价和 CPU 型号上完全看不出来**——必须逐台记详情页里的内存槽类型。

## 坑五：新数据不会自动带上旧约束

这是我觉得最值得单拎出来的一条，因为它不是平台的坑，是**方法的坑**。

第二轮我兴致勃勃地排出新短名单，把一款 N5105 的机器放在推荐位。
而同一个项目的选型文档里，早就写着：

> N5105 / N6005 有 Intel 微码缺陷，高连接数（4000–17000 活动连接）下会不定时软重启。
> 而跑透明代理**天然就是高连接数场景**。

**扫描数据是新鲜的，红线是旧的，新数据不会自动继承旧约束。**
我拿着刚出炉的价格表，把两周前自己写下的一票否决项忘得干干净净。

从那以后我加了一步：**排推荐名单前，对候选的每一个型号名，在项目文档里 grep 一遍。**
红线文档是一个采购项目里最贵的资产——它是历次踩坑攒出来的，
优先级**高于**本轮的新鲜数据。

## 坑六：外壳名字和散热方式没有关系

工控机圈子有「大背头 / 小背头」的说法，我一度以为大背头 = 更大的散热鳍片 = 被动散热。

同一个厂、同一个「大背头」外壳：
一款的详情写「标配 **8cm 温控风扇**」，另一款写「大背头**被动散热**效果更好」。
问卖家，原话是「大小背头**仅外壳区别**」。

**7×24 运行的网关，风扇是唯一的机械故障点**，这是我的硬红线。
而这条红线**只能靠逐条读详情或直接问卖家来守**，从型号名、外壳名、甚至 TDP 都推不出来。
我最后买的那台，详情页从头到尾没提散热——这成了我下单前唯一必须私聊问清的事。

## 坑七：「搜不到」只能说成「这组关键词没命中」

第一轮我扫完得出结论：「AMD 平台全出局，零结果。」
换了一组关键词之后，AMD 四网口软路由**一台不少地冒了出来**。

后来在两家店里逐条翻在售库存，又挖出两个关键词从没命中过的型号——
其中一个的单线程性能是**整张表最高的**，比我原本以为的天花板还高 19%。

> **交叉组合**：按「型号 × 形态 × 网卡 × 散热」四个维度组合关键词，
> 每个维度至少准备两种说法（`六网口` / `6口` / `6网`）。
> 然后**永远不要**把「没搜到」写成「不存在」。

## 性能怎么比：一条实测当锚，其余外推

要比较的东西是异构的——ARM 路由器 vs 不同世代的 x86，光堆 PassMark 分数没有意义。

我的做法是**在手上真能跑的机器上跑同一条基准**当锚点：

```bash
ssh <设备> 'openssl speed -elapsed rsa2048'
```

**RSA2048 的 sign/s 是最可靠的跨平台锚**：单次运算耗时远大于库调用开销，
受 OpenSSL 版本差异的影响最小。

⚠️ **两端 OpenSSL 大版本不同时，小块 AES 数据不可比**——
3.0 的 provider 调用开销大，我实测过 256B 以下 ARM 反而「更快」这种荒谬结果。
只用 16KB 档，或者干脆只用 RSA。

有了锚点再外推：

```
单核倍数  = 锚倍数 × (该 CPU PassMark 单线程 ÷ 锚 CPU 单线程)
总算力倍数 = 锚倍数 × (CPU Mark 比值)     ← 用 CPU Mark，不要用「核数 × 单核」
```

用 CPU Mark 而不是自己乘核数，因为它已经含了核数和超线程的实际收益。

报数的时候，**把锚点、外推公式、原始分都写出来，并注明哪些是实测、哪些是外推**。
我表里所有倍数都标着「外推」，只有一台是上机实测的。

### 然后我算出了一个反直觉的结果

我第一轮下单的那台机器，**总算力是现役旧路由器的 1.06 倍**。

不是 1.06 倍的提升——是**总算力基本持平**。它的单核确实快 2.3 倍，
但旧路由器是四核，新机是双核双线程，一乘一除，回到原点。

换句话说：**这次换机的收益全在内存**（旧设备内存吃紧），CPU 是原地踏步。
这是整个调研里最该告诉自己的一句话，而它只有在算出倍数之后才浮出来。

> **结论要落到「值不值」，不是「谁更快」。** 算出「新机 ≈ 现役」这种结果时，
> 它就是最重要的那条结论。

最后我改买了四核八线程那台，总算力 4.53 倍，多花了五百块——
**买的是「一台顶完」的余量**：网关 + 容器 + 未来的虚拟化，而不是更快的代理。

## 一个软件侧的提醒：别被商品标题带偏

这个品类的商品标题几乎全都写着「XX 软路由器 **爱快**软路由」。
爱快（iKuai）是国内常见的商用路由系统，标题这么写只是品类的通用叫法。

但如果你的核心需求是跑 Clash / mihomo 这类透明代理，**爱快是不行的**：
它是闭源系统，**没有插件仓库，装不了 OpenClash / mihomo**。
社区里「爱快 + 透明代理」的标准架构是 **爱快做主路由 + 另起一台 OpenWrt 做旁路由**。

如果你的目标和我一样是「一台顶完、把旧设备收掉」，那么装爱快意味着
**你还得再养一个 OpenWrt 实例**，层数不减反增。
OpenWrt 系（iStoreOS / ImmortalWrt / 官方版）才是对的方向。

**硬件参数看得再细，也别把软件生态漏了。**

## 十次改判的完整台账

我把每次推翻都记了下来，而不是静默改数字——因为**静默覆盖会让你自己在下一次
读到两个互相矛盾的版本**，而你已经不记得哪个是对的了。

| 原结论 | 改判为 | 原因 |
|---|---|---|

## 方法论：如果只记七条

1. **算整机价，不是挂牌价。** 准系统、加价、配件，全在详情页正文里。
2. **任何平台的挂牌价，在确认它不是区间起价之前，一律不可引用。** 淘宝有，二手平台也有。
3. **抓卖家主页先切到「在售」。** 已售商品的详情页看不出区别。但已售价是极好的成交锚点。
4. **配件单独扫一张基准价表，和主机分开买。** 卖家报价通常是市价的 2–4 倍。
   按价格排序后**逐条读正文**，最便宜的那几条往往是坏件。
5. **出推荐前，把每个候选型号名在自己的红线文档里 grep 一遍。**
   新数据不会自动继承旧约束，而红线文档是这个项目里最贵的资产。
6. **性能比较要有一条上机实测当锚**，其余按公开跑分外推，并且**标明哪些是实测哪些是外推**。
7. **结论落到「值不值」而不是「谁快」。** 算出「新机 ≈ 现役」这种反直觉结果时，那就是最重要的一条。

顺便说第八条，虽然它不是采购方法：**把每次改判都写下来，包括被推翻的旧结论和理由。**
这篇文章里最有价值的部分，就是那张台账——它比「最后买了哪台」有用得多。
