# 折 · FOLD

一张印了色的方格纸，一个动作：**拖动纸的一侧越过一条格线，它就翻过去盖在另一侧上。** 把纸折成右边「目标」的样子。

纯前端，零依赖零资源（音效由 WebAudio 合成），双击 `index.html` 即玩。

## 设计

规则只有一句，深度来自四件事的叠加，四个章节各引入一件：

| 章 | 引入 | 决策变成什么 |
|---|---|---|
| 对折 | 翻过去的那面朝下，露出纸背（素色） | 目标里的素色只能靠翻面得到 |
| 层叠 | 纸越折越厚，只看最上面一层 | 折的**顺序**决定谁盖住谁 |
| 双面 | 纸背也印色（点纹标出纸背） | 翻面不再是「抹掉」，而是「换图」；一格可能要翻两次 |
| 镂空 | 有的格子被剪掉 | 洞盖上来透出下层；洞落到桌面就是空 |

其它设计选择：

- **每关内置求解器**（`js/model.js` 的 `solve`，按状态 BFS）。关卡由程序生成：先随机折 N 次得到目标，再用求解器证明 N-1 折内**不可达**，于是「最少折数」恰好等于设计折数，三星门槛不是拍脑袋。
- **纸的厚度可见**：每格按层数画出右/下沿的纸边和更深的投影，玩家能读出哪里厚——这是层叠章的关键信息。
- **纸背有点纹、洞有凹陷阴影**：看一眼就知道自己看到的是正面、背面还是下一层。
- **提示不是答案生成器，是求解器的第一步**；若当前局面已折不到目标，提示会明说「退回去」而不是沉默。
- **每日一折**：按日期生成一张 6×6 双面带洞四折的纸。

## 操作

| 操作 | 键 |
|---|---|
| 折叠 | 从纸的一侧按住，拖越过一条格线（鼠标 / 触屏） |
| 撤销 / 重来 / 提示 / 静音 | `Z` / `R` / `H` / `M` |
| 通关后下一张 | `N` |

进度与静音状态存 `localStorage`。

## 文件

```
index.html      壳与 DOM
style.css       版式
js/model.js     纸的模型（Map<格,层栈>）、折叠、可见面、求解器
js/levels.js    章节/关卡表与程序生成（求解器验证最少折数）
js/audio.js     WebAudio 合成音效
js/render.js    Canvas 绘制：纸面/厚度/点纹/洞/折线高亮/翻页动画
js/main.js      状态、拖拽交互、UI、通关
```

调试钩子：`window.__FOLD`（`G` 当前局面、`fold`/`solve`/`pattern`、`loadLevel`、`selfTest()`）。
